# Little Dinosaurs Place · Caso de portafolio y demo anonimizada

Demo estática original y anonimizada, creada para acompañar una experiencia de actualización de un sitio en **WordPress / Elementor**. La marca ficticia «Casa Brote» y todos los textos e ilustraciones de esta muestra son material de demostración.

## Relación con el trabajo real

El proyecto real es **Little Dinosaurs Place**. Según el trabajo reportado, se publicó una versión en español e inglés y se conservó la página de inicio original para facilitar una reversión.

El trabajo de referencia consistió en una actualización de contenido y presentación en WordPress / Elementor, incluyendo una landing, un aviso temporal de mudanza, un selector de idioma español/inglés y ajustes del menú móvil. **Este repositorio no contiene el código WordPress del sitio real**, una exportación de Elementor, un tema, un plugin ni una copia de su diseño. Es una implementación independiente en HTML, CSS y JavaScript que permite mostrar esos tipos de interacción sin divulgar material del cliente.

No se atribuyen al proyecto real funcionalidades de este demo que no estén verificadas. No se afirma haber validado todas las rutas históricas, el envío de correos de formularios, métricas de conversión, resultados comerciales ni auditorías completas de accesibilidad o rendimiento.

## Qué demuestra este código

- Landing adaptable a escritorio y móvil.
- Cambio de idioma ES / EN sin servicios externos.
- Menú móvil funcional, con estado accesible y cierre con Escape o al elegir un enlace.
- Aviso editorial temporal y secciones con navegación interna.
- Ilustraciones abstractas originales hechas con CSS, sin fotografías.
- Estados de foco y respeto de la preferencia de movimiento reducido.

## Privacidad y límites

No incluye datos de contacto, dirección, fechas de mudanza reales, logos del cliente, fotos de niños, testimonios, archivos privados, formularios activos, analítica, cookies ni llamadas a servicios externos. No recopila datos. Los textos describen una entidad ficticia, no los servicios comprobados de una institución real. La demo no tiene un despliegue independiente ni está conectada a un dominio. La publicación de este repositorio no equivale a desplegar un sitio web.

## Ver localmente

Abre `index.html` directamente en un navegador. No necesita dependencias, compilación ni instalación. También se puede servir como cualquier sitio estático.

## Estructura

- `index.html`: contenido semántico y traducciones.
- `styles.css`: diseño responsive e ilustraciones originales.
- `script.js`: selector de idioma y navegación móvil.
- No se incluyen capturas: el renderizado local no estuvo disponible en este entorno.

## Uso honesto en portafolio

Presentar la experiencia real como «Actualización web en WordPress / Elementor» y el código como «Demo estática original y anonimizada del tipo de experiencia implementada». Cualquier captura futura de esta demo debe rotularse como demo conceptual, nunca como captura de producción del cliente.

## Verificación de esta entrega

Sintaxis de JavaScript y estructura estática de traducciones/enlaces comprobadas. La ejecución de Chromium estuvo bloqueada por el entorno; no se afirma una prueba visual ni funcional completa en navegador. Antes de desplegar, comprobar ES/EN, navegación móvil, ausencia de desbordamiento y presentación en dispositivos reales.
